# Exelena Motion

Hero-экран футбольной академии **Exelena**. Игрок на фоне поворачивает голову вслед за курсором.

Это статичная страница на чистых HTML, CSS и JS: без сборки и без зависимостей в рантайме.

## Запуск

```bash
python3 -m http.server 8765
# открыть http://127.0.0.1:8765/
```

Страницу можно открыть и прямо из файла (`index.html`), но шрифты Google Fonts и `canvas` надёжнее работают через локальный сервер.

## Что внутри

```
index.html              разметка
assets/css/style.css    стили: десктоп на сетке макета + адаптив
assets/js/main.js       слежение головы за курсором (canvas) и бургер-меню
assets/img/             только WebP
  bg.webp               фон: стадион, глобус, кристаллы (сгенерирован codex)
  logo.webp             герб академии (codex)
  icons/*.webp          иконки (codex, PNG → WebP)
  player/body.webp      статичный торс игрока
  player/f00…f40.webp   41 кадр поворота головы из видео
tools/                  скрипты, которыми собраны ассеты, и промпты для codex
```

## Как устроен поворот головы

1. Из исходного видео (752×416, 24 fps) взят отрезок кадров 34–74, где игрок поворачивает голову справа налево.
2. Кадры выровнены по торсу (фазовая корреляция), чтобы двигалась только голова.
3. Игрок вырезан из фона моделью rembg `isnet-general-use`. Фон видео чёрный, но футболка тоже чёрная, поэтому одного ключа по яркости мало. Итоговая альфа складывается из трёх частей: ядро маски, выпуклая оболочка торса и ключ по яркости на краях волос.
4. В видео игрок обрезан по грудь. Низ майки с надписью EXELENA и гербом дорисовал codex (outpaint на зелёном фоне + хромакей).
5. В браузере тело и текущий кадр рисуются на одном `<canvas>`. Положение курсора относительно головы задаёт целевой кадр, а текущий плавно догоняет его (lerp).
   - курсор левее головы — кадры 18 → 40, игрок смотрит влево;
   - курсор правее — кадры 18 → 0, смотрит вправо;
   - курсор ушёл со страницы — нейтральный кадр 18.

При `prefers-reduced-motion: reduce` голова не двигается.

## Вёрстка

- **≥ 1024 px.** Вёрстка один в один повторяет макет 1591×989. Любой размер задан как `calc(N * var(--k))`, где `--k = 100vw / 1591`, поэтому страница масштабируется пропорционально.
- **< 1024 px.** Блоки идут друг за другом в столбик, навигация убрана в бургер-меню.
- **< 560 px.** Статистика выстраивается сеткой 2×2.

Совпадение с макетом проверяется скриптом `tools/compare.py`. Он делает скриншот при окне 1591×989 и выводит расхождение рамок ~30 элементов с референсом. Сейчас почти все они в пределах ±1–2 px.

## Пересборка ассетов

Исходники (`references/reference.png`, `references/video.mp4`) в репозиторий не входят. Чтобы пересобрать ассеты, положите их в `references/`.

```bash
pip install -r tools/requirements.txt

# 1. картинки: сгенерировать PNG через codex по промптам из tools/prompts/,
#    сложить в .work/gen/*.png, затем:
python tools/build_images.py

# 2. игрок
python tools/build_player.py all        # кадры → маски → матты → .work/torso_in.png
codex exec --skip-git-repo-check --sandbox workspace-write -C .work \
  -i torso_in.png - < tools/prompts/torso.txt   # → .work/torso.png
python tools/build_player.py export     # → assets/img/player/*.webp

# 3. сверка с макетом
python3 -m http.server 8765 &
python tools/compare.py
```

`build_player.py export` выводит константы `FRAMES` и `BODY`. Если они изменились, обновите их в `assets/js/main.js`.

## Ограничения

- Игрок на странице — это человек из видео, а не с макета. Его ракурс и свет отличаются; на canvas наложена тёплая цветокоррекция.
- Во всех фронтальных кадрах видео глаза скошены в сторону, взгляда в камеру в исходнике нет.
- Видео низкого разрешения растянуто в 1.8 раза, поэтому лицо мягче, чем на макете.
- Фон сгенерирован заново: композиция совпадает с макетом, но не попиксельно.
- Шрифты — Montserrat и Inter. Ширину текста под макет подгоняли межбуквенными интервалами.
